Простое веб-приложение с тремя страницами.

## Лаб 4 — Telegram бот

Бот с командами, регистрацией (многошаговый диалог), inline-кнопками и базой данных SQLite.

### Функции
- `/start` — главное меню с кнопками
- `/register` — регистрация (имя → возраст)
- `/profile` — просмотр профиля
- `/stats` — статистика бота
- `/help` — справка

### Запуск
```bash
cd lab4_bot

# 1. Установить зависимости
pip install -r requirements.txt

# 2. Создать файл .env с токеном
echo BOT_TOKEN=твой_токен > .env

# 3. Запустить
python bot.py
```
