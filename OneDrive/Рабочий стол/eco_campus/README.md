# 🌿 EcoCampus РУДН — Эко-логистика кампуса

> Интеллектуальная система навигации к экопунктам раздельного сбора отходов на территории кампуса РУДН

---

## 🎯 О проекте

EcoCampus — это практический инструмент, решающий реальную проблему: студенты не знают, **куда и как** сдать раздельные отходы в кампусе. Сервис строит оптимальный пешеходный маршрут от текущей точки до ближайшего подходящего контейнера — по типу мусора.

### Целевая аудитория
- **Студенты и сотрудники РУДН** — через Telegram-бот
- **Администрация кампуса** — через REST API (мониторинг, интеграция с другими сервисами)

---

## 🏗️ Архитектура

Проект реализован по принципу **слоистой архитектуры** со слабой связанностью модулей:

```
eco_campus/
├── core/               # Доменная логика (независима от фреймворков)
│   ├── models.py       # Доменные модели: Container, Route, WasteType
│   ├── router.py       # Движок маршрутизации (алгоритм Дейкстры)
│   ├── exceptions.py   # Кастомная иерархия исключений
│   └── logger.py       # Профессиональное логирование
├── data/
│   └── campus_data.py  # База данных узлов, рёбер и контейнеров РУДН
├── api/
│   └── app.py          # FastAPI REST-сервер
├── bot/
│   └── telegram_bot.py # Telegram-бот (интерфейс для студентов)
└── tests/
    ├── test_router.py  # Unit-тесты (модели, маршрутизатор)
    └── test_api.py     # Интеграционные тесты (API)
```

**Принципы:**
- Слой `core` не знает ничего о FastAPI или Telegram — полная независимость
- Каждый модуль отвечает за одну зону ответственности (Single Responsibility)
- Graceful Degradation: битая запись контейнера не ломает весь поиск

## 🤖 ИИ-компонент

Маршрутизация реализована через граф кампуса и алгоритм **Дейкстры** (библиотека NetworkX):

- **Граф**: 15 ключевых точек (узлов) кампуса, 21 пешеходный маршрут (рёбра), взвешенные по расстоянию в метрах
- **Задача**: найти ближайший контейнер для заданного типа отходов с минимальной суммарной дистанцией
- **Оценка времени**: расчёт на основе средней скорости пешехода 80 м/мин

## 🚀 Запуск

### Требования
- Python 3.11+
- pip

### Установка

```bash
git clone <repo>
cd eco_campus
pip install -e ".[dev]"
```

### Запуск API-сервера

```bash
uvicorn eco_campus.api.app:app --reload
# Документация: http://localhost:8000/docs
```

### Запуск Telegram-бота

```bash
export TELEGRAM_BOT_TOKEN=your_token_here
python -m eco_campus.bot.telegram_bot
```

### Запуск тестов

```bash
pytest tests/ -v --cov
```

## 🏢 Бизнес-потенциал

**Конкуренты:** EcoPoint (умные пункты приёма), GreenCity (эко-карты городов)

**Отличие:** EcoCampus заточен под закрытую территорию (кампус, бизнес-парк, жилой комплекс) — не требует GPS, работает по внутренней топологии.

**Модели монетизации:**
1. **B2B — университеты и корпорации**: лицензия на развёртывание для своей территории
2. **B2G — муниципалитеты**: интеграция с городскими программами раздельного сбора
3. **Расширение**: аналитика для администрации (какие контейнеры переполнены, тепловая карта активности)

**Масштабирование**: замена `campus_data.py` на любой другой граф позволяет развернуть систему в любом кампусе за 1 день.
